The available public distribution is the [UnlimGPT CLI package in the npm registry](https://registry.npmjs.org/@unlimgpt%2fcli). It selects a platform-specific executable for supported macOS, Linux and Windows architectures. Use a package-manager installation until a public standalone release is available.

## Install

Check the published version, then install the package with npm:

```bash
npm view @unlimgpt/cli version
npm install --global @unlimgpt/cli
```

For a reproducible installation, append the version you just checked to the package name. The npm package manager needs its own runtime to install and launch the package. A future standalone binary will have different installation steps.

## Verify

Run:

```text
unlimgpt --version
unlimgpt --help
```

Use only commands shown by the installed release. If `configure` is absent, check for a newer package before following the [client guide](/docs/getting-started/first-client).

## Update or remove

To update, check the published version and reinstall the package. To remove it, run `npm uninstall --global @unlimgpt/cli`. Run `unlimgpt logout` before removal if you also want to revoke the CLI authorization. API keys remain independent and are revoked separately in [API keys](/api-keys) or with `unlimgpt keys revoke`.
