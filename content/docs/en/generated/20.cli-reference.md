Install the [published @unlimgpt/cli package](/docs/cli/install). Before using a command, check your installed version with `unlimgpt --version` and available commands with `unlimgpt --help`: this reference may describe a newer release.

## `login`

Sign in by approving a device code in your browser.

```text
unlimgpt login [--no-browser] [--server <https-origin>]
```

## `logout`

Revoke the CLI OAuth session and remove its local refresh token.

```text
unlimgpt logout
```

## `whoami`

Inspect the current user and organization.

```text
unlimgpt whoami [--json]
```

## `models`

List every available model and its capabilities.

```text
unlimgpt models [--json]
```

## `organizations`

List your organizations or select an organization for the current profile.

```text
unlimgpt organizations <list [--json]|use <organization-id>>
```

## `keys`

Manage API keys for the current organization. `keys permissions <key-id> --scope models:read --scope inference:write` replaces the permission set; `--clear` removes both permissions and `--json` returns safe metadata. `keys spend-limit <key-id> --micro-credits <amount>` sets the total key budget: 0 denies new spending and `--clear` removes the cap without resetting spent credits.

```text
unlimgpt keys <list|create|revoke|rotate|permissions|policy|spend-limit>
```

## `configure`

Configure a client or show manual steps; `cloud` and `claude` alias `claude-code`.

```text
unlimgpt configure <client> [--profile <name>] [--model <id>] [--dry-run] [--yes]
```

## `revert`

Revert an owned change when the file has not changed since setup.

```text
unlimgpt configure revert <receipt-id>
```

## `doctor`

Run free diagnostics; the paid probe requires explicit opt-in.

```text
unlimgpt doctor [--client <id>] [--json] [--probe --yes]
```

## `update`

Show the published version. With --yes, npm installs that exact release and leaves profiles, sign-in and API keys in place.

```text
unlimgpt update [--yes]
```

## `credential`

Return a key only to a native credential helper through stdout.

```text
unlimgpt credential get --account <id> --kind api-key
```

## `launch`

Launch a child process with an ephemeral secret environment; `--profile` selects a saved profile without changing the active one.

```text
unlimgpt launch <openai|anthropic|continue> [--profile <name>] -- <command> [args...]
```

## `clients`

Show the current client support matrix.

```text
unlimgpt clients [--json]
```

## `completion`

Generate shell completion.

```text
unlimgpt completion <bash|zsh|fish|powershell>
```
