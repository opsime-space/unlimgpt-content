## Prerequisites

- Install the [published `@unlimgpt/cli` package](/docs/cli/install).
- Install Roo Code and confirm it offers an OpenAI-compatible endpoint and API key field.

## Setup

- Run `unlimgpt configure roo` and open Roo Code → API configuration profiles → OpenAI Compatible.
- Copy the displayed Base URL and model ID. The CLI temporarily copies the API key to the clipboard.
- Paste the API key from the clipboard only into Roo Code's native secret field; the CLI never reads SQLite or VS Code SecretStorage.

## Verify

- Open Roo Code, send “Reply with READY” through the configured model, wait for a non-empty response, and confirm the request in [API Activity](/api-activity). The wording may vary; the request uses credits.

## Rotate

- Record the old key ID from `unlimgpt keys list`, create a new key with `unlimgpt keys create --name roo-next`, then rerun `unlimgpt configure roo` to copy the new key.
- Paste it into Roo Code's native secret field. Send a real request in Roo Code and confirm it in [API Activity](/api-activity); only then revoke the old key on the API keys page.

## Revoke

- Revoke a key on the [API keys page](/api-keys) after confirming the new connection; the old key immediately loses access.

## Revert

- The CLI did not modify Roo Code; remove the key and model through its UI.

## Troubleshooting

| Problem | Resolution |
| --- | --- |
| There is no custom endpoint field. | Upgrade Roo Code and select its official OpenAI-compatible provider; the CLI does not automate hidden internal formats. |
| Requests fail after setup. | Verify the selected provider, Base URL, and model id, then run doctor. |

If the request fails, run `unlimgpt doctor --client roo` and see [troubleshooting](/docs/troubleshooting/doctor). Diagnostics do not replace a real request.

## Uninstall

- Remove the UnlimGPT profile and secret through Roo Code's UI, then revoke the dedicated API key.
