## Prerequisites

- Install the [published `@unlimgpt/cli` package](/docs/cli/install).
- Setup signs you in and creates an API key if needed; the secret stays in the operating-system credential store.

## Setup

- Preview the YAML fields that would change: `unlimgpt configure continue --dry-run`.
- Apply it: `unlimgpt configure continue`.
- Start the CLI with `unlimgpt launch continue -- cn --config ~/.continue/config.yaml`; configure the IDE extension separately through its native secret UI.

## Verify

- Run `unlimgpt launch continue -- cn --config ~/.continue/config.yaml`. If you configured `--profile work`, use `unlimgpt launch continue --profile work -- cn --config ~/.continue/config.yaml` with your actual profile name. The `--config` flag opens the local YAML even when a different config was previously selected. In Continue CLI, use `/model` to select the UnlimGPT model, send “Reply with READY”, wait for a non-empty response, and confirm the request in [API Activity](/api-activity). The wording may vary; the request uses credits.

## Rotate

- Record the old key ID from `unlimgpt keys list`, then create a new key with `unlimgpt keys create --name rotated-client`.
- Relaunch the client through UnlimGPT, send a request, and confirm it in [API Activity](/api-activity). Revoke the old key only afterward.

## Revoke

- Revoke a key on the [API keys page](/api-keys) after confirming the new connection; the old key immediately loses access.

## Revert

- Run the exact command printed after `Undo:` by `configure`. The CLI leaves later third-party edits intact.

## Troubleshooting

| Problem | Resolution |
| --- | --- |
| The YAML uses anchors or directives. | The CLI stops before writing; use guided setup so YAML semantics are preserved. |
| The IDE cannot read the shell variable. | That is expected for the extension: use Continue's native UI/Hub instead of a plaintext `.env`. |

If the request fails, run `unlimgpt doctor --client continue` and see [troubleshooting](/docs/troubleshooting/doctor). Diagnostics do not replace a real request.

## Uninstall

- Run the guarded revert and remove the native Continue secret if you created one for the IDE.
