## Prerequisites

- Install the [published `@unlimgpt/cli` package](/docs/cli/install).
- Setup signs you in and creates an API key if needed; the secret stays in the operating-system credential store.

## Setup

- Configure Codex CLI 0.156.1 with `gpt-6-sol`. This command does not yet support other models.
- Preview the fields that would change, without writing: `unlimgpt configure codex --dry-run`.
- Quit Codex Desktop. If previous sessions exist, after writing `config.toml` the CLI creates a backup of Codex session stores in its `backups` directory; it includes chat content. Keep it private.
- Apply the owned block: `unlimgpt configure codex`.
- The CLI adds the `unlimgpt` provider; the secret stays in the OS credential store and is returned through `auth.command`.

## Verify

- Reopen Codex Desktop and confirm your previous chats are still visible.
- Start a new Codex chat, send “Reply with READY”, wait for a non-empty response, and confirm the request in [API Activity](/api-activity). The wording may vary; the request uses credits.

## Rotate

- Record the old key ID from `unlimgpt keys list`, then create and select a new key with `unlimgpt keys create --name codex-next`.
- Send a request in Codex and confirm it in [API Activity](/api-activity); restart Codex if needed. Revoke the old key only after a successful request.

## Revoke

- Revoke a key on the [API keys page](/api-keys) after confirming the new connection; the old key immediately loses access.

## Revert

- Run the exact command printed after `Undo:` by `configure`. The CLI leaves later third-party edits intact.

## Troubleshooting

| Problem | Resolution |
| --- | --- |
| Codex does not support `auth.command`. | Upgrade to a Codex release with native provider auth commands; plaintext fallback is intentionally unavailable. |
| Another provider is active. | Inspect the effective user-level `$CODEX_HOME/config.toml`, then rerun `unlimgpt configure codex`. |

If the request fails, run `unlimgpt doctor --client codex` and see [troubleshooting](/docs/troubleshooting/doctor). Diagnostics do not replace a real request.

## Uninstall

- Run the guarded receipt revert, then revoke the dedicated Codex key if no other client uses it.
