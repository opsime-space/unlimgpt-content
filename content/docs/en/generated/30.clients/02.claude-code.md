## Prerequisites

- Install the [published `@unlimgpt/cli` package](/docs/cli/install).
- Setup signs you in and creates an API key if needed; the secret stays in the operating-system credential store.

## Setup

- Review precedence and the fields that would change: `unlimgpt configure claude-code --dry-run`.
- Apply the configuration: `unlimgpt configure claude-code`.
- The CLI never writes the key to JSON; Claude Code obtains it through `apiKeyHelper`.

## Verify

- Open Claude Code, send “Reply with READY”, wait for a non-empty response, and confirm the request in [API Activity](/api-activity). The wording may vary; the request uses credits.

## Rotate

- Record the old key ID from `unlimgpt keys list`, then create and select a new key with `unlimgpt keys create --name claude-code-next`.
- Send a request in Claude Code and confirm it in [API Activity](/api-activity); restart Claude Code if needed. Revoke the old key only after a successful request.

## Revoke

- Revoke a key on the [API keys page](/api-keys) after confirming the new connection; the old key immediately loses access.

## Revert

- Run the exact command printed after `Undo:` by `configure`. The CLI leaves later third-party edits intact.

## Troubleshooting

| Problem | Resolution |
| --- | --- |
| The helper is not called. | Remove a higher-precedence `ANTHROPIC_AUTH_TOKEN` or `ANTHROPIC_API_KEY`, then rerun doctor. |
| Managed settings prevent changes. | Contact your administrator; the CLI does not bypass managed policy. |

If the request fails, run `unlimgpt doctor --client claude-code` and see [troubleshooting](/docs/troubleshooting/doctor). Diagnostics do not replace a real request.

## Uninstall

- Run the guarded receipt revert, then revoke the dedicated Claude Code key.
