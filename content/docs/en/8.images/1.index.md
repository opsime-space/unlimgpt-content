This section groups models for working with images. Each model family's guide describes its parameters, input files and result format.

## Models

| Family | Availability | Guide |
| --- | --- | --- |
| GPT Image | Coming soon | [GPT Image](/docs/gpt-image) |
| Nano Banana | Per connection | [Nano Banana](/docs/nano-banana) |

Access depends on your connection and API key permissions. Use only the models and methods enabled for your connection.

## Choose a task

- **Generation** — create a new image from a text description.
- **Editing** — provide a source image and describe the changes.
- **Analysis** — send an image to a chat model that accepts image inputs; see [media inputs](/docs/api/reasoning-and-media).

Generation and editing have their own parameters and result formats. Check the selected model's guide before using video or chat settings in an image request.
