## September 23, 2026 — CLI 0.1.2 on npm

Version 0.1.2 of `@unlimgpt/cli` was published to the [npm registry](https://registry.npmjs.org/@unlimgpt%2fcli) on September 23, 2026. Run `unlimgpt --version` to check your installed version and `unlimgpt --help` for the commands actually available in it. A Git-tagged version absent from npm cannot be installed through the normal registry command. If a guide refers to a command unavailable in your release, use the manual step in [client configuration](/docs/cli/configure).

The installed 0.1.2 help lists `login`, `logout`, `whoami`, `models`, `keys`, `configure`, `doctor`, `credential get`, `launch`, `clients`, and `completion`. Use [configure](/docs/cli/configure) to connect a client; run doctor when troubleshooting. Preserve your client configuration and receipt before updating, then repeat the free `GET /v1/models` check.
