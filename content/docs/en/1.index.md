Set `BASE_URL` to your HTTPS API origin without a trailing slash or `/v1`, and pass `API_KEY` from your credential store. OpenAI-compatible SDKs use `${BASE_URL}/v1`; Anthropic-compatible SDKs use `BASE_URL`.

Chat and API use one account; API access depends on the plan and key permissions. Configure your client with its protocol's **base URL**, not a single request URL:

| Client or protocol | Base URL | Path the client calls |
| --- | --- | --- |
| OpenAI Responses and Chat Completions | `${BASE_URL}/v1` | `/responses` or `/chat/completions` |
| Anthropic Messages | `BASE_URL` | `/v1/messages` |

Pass the raw key only through the client's supported credential setting; never append it to the URL. The [compatibility matrix](/docs/reference/clients) shows the exact setup mode for each AI client.

## Minimal Responses request

After [creating an API key](/docs/account/api-keys), set `API_KEY` in your shell from a secure store. Choose a model ID returned by the free [model catalog](/docs/api/models); replace the sample ID if your account lists a different model. This request can consume credits.

::code-group
#curl
~~~bash
printf 'Authorization: Bearer %s\n' "$API_KEY" \
  | curl -q -H @- "$BASE_URL/v1/responses" \
    -H "Content-Type: application/json" \
    -d '{
  "model": "gpt-5.6-sol",
  "input": "Say hello in one sentence.",
  "max_output_tokens": 64,
  "stream": false,
  "store": false
}'
~~~

#python
~~~python
import json
import os
import urllib.request


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, request, fp, code, msg, headers, newurl):
        return None


opener = urllib.request.build_opener(NoRedirect)

base_url = os.environ["BASE_URL"]
key = os.environ["API_KEY"]

request = urllib.request.Request(
    base_url + "/v1/responses",
    headers={
        "Authorization": f"Bearer {key}",
        "Content-Type": "application/json",
    },
    data=json.dumps(
        {
            "model": "gpt-5.6-sol",
            "input": "Say hello in one sentence.",
            "max_output_tokens": 64,
            "stream": False,
            "store": False,
        }
    ).encode("utf-8"),
)

with opener.open(request, timeout=120) as response:
    print(response.status, response.headers.get("request-id"))
    print(response.read().decode("utf-8"))
~~~
#go
~~~go
package main

import (
	"fmt"
	"io"
	"net/http"
	"os"
	"strings"
	"time"
)

func main() {
	client := &http.Client{
		Timeout: 120 * time.Second,
		CheckRedirect: func(*http.Request, []*http.Request) error {
			return http.ErrUseLastResponse
		},
	}
	baseURL := os.Getenv("BASE_URL")
	if baseURL == "" {
		panic("BASE_URL is required")
	}
	key := os.Getenv("API_KEY")
	if key == "" {
		panic("API_KEY is required")
	}

	req, err := http.NewRequest(
		"POST",
		baseURL+"/v1/responses",
		strings.NewReader(`{
  "model": "gpt-5.6-sol",
  "input": "Say hello in one sentence.",
  "max_output_tokens": 64,
  "stream": false,
  "store": false
}`),
	)
	if err != nil {
		panic(err)
	}
	req.Header.Set("Authorization", "Bearer "+key)
	req.Header.Set("Content-Type", "application/json")

	response, err := client.Do(req)
	if err != nil {
		panic(err)
	}

	fmt.Println(response.StatusCode, response.Header.Get("request-id"))
	if _, err := io.Copy(os.Stdout, response.Body); err != nil {
		panic(err)
	}
	response.Body.Close()
}
~~~
::

The response contains `id`, `status`, `model`, `output_text`, structured `output`, and `usage`. The text is also available in an `output[].content[]` block of type `output_text`. This example explicitly avoids storing a retrievable response; activity metadata is still recorded. Check the recent operation's endpoint, time and outcome in [API Activity](/api-activity). Its row ID differs from the HTTP `request-id` header. See the [complete first-request guide](/docs/getting-started/first-api-request) before sending it.
