Set `BASE_URL` to your HTTPS API origin without a trailing slash or `/v1`, and pass `API_KEY` from your credential store. OpenAI-compatible SDKs use `${BASE_URL}/v1`; Anthropic-compatible SDKs use `BASE_URL`.

Send `Idempotency-Key` when your application may retry an inference call after a timeout or connection loss. Generate one fresh, unpredictable value per new logical request and store it alongside the exact request parameters. Reuse the same value **and parameters** for every retry of that request. Within 24 hours, a completed duplicate returns its terminal result without another generation or charge. A new user request needs a new key, even if its prompt happens to match.

## Send and retain one logical request

Make sure `API_KEY` is available to the process. In a shell with OpenSSL, generate one random key; in an application, use your cryptographically secure UUID generator or equivalent. Keep the idempotency value and body in application state until the call has a terminal outcome. Do not put an API key or prompt inside the idempotency value.

~~~bash
export UNLIMGPT_REQUEST_KEY="$(openssl rand -hex 16)"
~~~

Send the request from the same shell. If key generation failed, the check stops the request before paid work:

::code-group
#curl
~~~bash
test -n "${UNLIMGPT_REQUEST_KEY:-}" \
  && printf 'Authorization: Bearer %s\n' "$API_KEY" \
  | curl -q -H @- -i "$BASE_URL/v1/responses" \
    -H "Content-Type: application/json" \
    -H "Idempotency-Key: $UNLIMGPT_REQUEST_KEY" \
    -d '{
  "model": "gpt-5.6-sol",
  "input": "Say hello.",
  "max_output_tokens": 64,
  "stream": false
}'
~~~

#python
~~~python
import json
import os
import urllib.request


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, request, fp, code, msg, headers, newurl):
        return None


opener = urllib.request.build_opener(NoRedirect)

base_url = os.environ["BASE_URL"]
key = os.environ["API_KEY"]
request_key = os.environ["UNLIMGPT_REQUEST_KEY"]

request = urllib.request.Request(
    base_url + "/v1/responses",
    headers={
        "Authorization": f"Bearer {key}",
        "Content-Type": "application/json",
        "Idempotency-Key": request_key,
    },
    data=json.dumps(
        {
            "model": "gpt-5.6-sol",
            "input": "Say hello.",
            "max_output_tokens": 64,
            "stream": False,
        }
    ).encode("utf-8"),
)

with opener.open(request, timeout=120) as response:
    print(response.status, response.headers.get("request-id"))
    print(response.read().decode("utf-8"))
~~~
#go
~~~go
package main

import (
	"fmt"
	"io"
	"net/http"
	"os"
	"strings"
	"time"
)

func main() {
	client := &http.Client{
		Timeout: 120 * time.Second,
		CheckRedirect: func(*http.Request, []*http.Request) error {
			return http.ErrUseLastResponse
		},
	}
	baseURL := os.Getenv("BASE_URL")
	if baseURL == "" {
		panic("BASE_URL is required")
	}
	key := os.Getenv("API_KEY")
	if key == "" {
		panic("API_KEY is required")
	}
	requestKey := os.Getenv("UNLIMGPT_REQUEST_KEY")
	if requestKey == "" {
		panic("UNLIMGPT_REQUEST_KEY is required")
	}

	req, err := http.NewRequest(
		"POST",
		baseURL+"/v1/responses",
		strings.NewReader(`{
  "model": "gpt-5.6-sol",
  "input": "Say hello.",
  "max_output_tokens": 64,
  "stream": false
}`),
	)
	if err != nil {
		panic(err)
	}
	req.Header.Set("Authorization", "Bearer "+key)
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Idempotency-Key", requestKey)

	response, err := client.Do(req)
	if err != nil {
		panic(err)
	}

	fmt.Println(response.StatusCode, response.Header.Get("request-id"))
	if _, err := io.Copy(os.Stdout, response.Body); err != nil {
		panic(err)
	}
	response.Body.Close()
}
~~~
::

Expect a terminal JSON response on success. Save the HTTP `request-id` for diagnostics; it is different from a run ID in [API Activity](/api-activity). For a retry, run **only the second block** with the same variable and unchanged body. Rerunning the OpenSSL command creates a new key and may start a second paid generation.

## Decide whether to retry

- A duplicate while its first execution is active returns temporary HTTP 409 with `retry-after: 1` and `x-should-retry: true`. Wait at least the advised time, then send the unchanged request with the same key.
- The same key with changed parameters returns a permanent 409 and `x-should-retry: false`. Treat it as an application bug; choose a new key only for a genuinely new logical request.
- For HTTP 429, read `retry-after` and `x-should-retry`. A transient rate limit may be retried after its delay; a package usage limit needs its reset or a plan change. Do not loop on `x-should-retry: false`.
- For a broken stream, inspect Activity and the last native event before deciding what happened. A stream may carry its failure after HTTP 200; use the same key for a safe retry when the client supports that behavior.

Bound your own retry count and total elapsed time. Do not automatically retry a non-retryable public error or change the request body while retaining its old key. See [streaming](/docs/api/streaming), [errors and limits](/docs/api/errors-and-limits), and [Responses](/docs/api/responses) for the protocol context.
