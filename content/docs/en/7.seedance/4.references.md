## Supported inputs

The table describes model capabilities. Availability depends on your assigned connection and key. These examples describe accepted request shapes; confirm advanced mode access before placing an order.

| Scenario | Support |
|---|---|
| Text to video | All four models |
| Image to video | First frame, first and last frames, or reference images; Mini/Fast require text; their audio references also require an image or video |
| Image + video + audio | Supported together |
| Audio without image/video | 2.5 only |
| Edit and extend | 2.5 with `omni_reference_task_type` |
| Draft and final upgrade | 2.5 |

References use extension fields: `image_urls`, `video_urls` and `audio_urls` contain HTTPS URLs. Use `image_with_roles: [{"url":"REFERENCE_URL","role":"first_frame"}]` for image roles `reference_image`, `first_frame` or `last_frame`. Multipart video uploads are not supported. These modes require reference access on your connection.

Do not mix first/last-frame images with `reference_image`. On 2.5, frame roles can accompany video or audio references; on other models, they cannot. Use at most one image for each frame role; a last frame needs a first frame. Use `aspect_ratio: "adaptive"` for frame mode, editing and extending. Crop or pad the first image in advance to obtain the intended proportions.

## File requirements

| Input | Formats and size |
|---|---|
| Image | JPEG, PNG, WebP, BMP, TIFF, GIF, HEIC or HEIF; less than 30 MB |
| Video | MP4 or MOV; at most 200 MB; 24–60 fps |
| Audio | WAV or MP3; at most 15 MB |

Images and videos must be 300–6000 pixels in width and height, with width/height from 0.4 to 2.5. Video also needs 407,696–8,295,044 pixels per frame. MP4 supports H.264/AVC or H.265/HEVC video with AAC or MP3 audio; MOV also permits PCM audio.

Use direct HTTPS file URLs accessible without login, cookies or extra authorization headers. Local paths and media viewer pages do not work. A signed URL must remain valid while the service retrieves the input; do not log its access parameters.

| Model | Maximum images | Maximum videos | Maximum audio clips | Duration of each video/audio and separate total limits |
|---|---|---|---|---|
| 2.0/Mini/Fast | 9 | 3 | 3 | 2–15 s per clip, at most 15 s total for each media type |
| 2.5 | 30 | 10 | 10 | 2–30 s per clip, at most 30 s total for each media type |

A 2.5 editing input video must be 4–30 seconds. Audio references and generated output audio are separate settings.

## Reference examples

Replace all example URLs with your media. Each new POST creates a separate potentially billable task. The examples use English prompts, supported by all listed models.

### Image reference

```json
{
  "model": "seedance-2.5",
  "resolution": "720p",
  "generate_audio": true,
  "prompt": "Animate the landscape in the image. Preserve the house, mountain outlines, shoreline and colors. The camera smoothly moves forward, water ripples gently and clouds drift slowly. One continuous shot, no location changes or captions.",
  "image_with_roles": [
    {
      "url": "REFERENCE_REFERENCE_JPG_URL",
      "role": "reference_image"
    }
  ],
  "seconds": "30",
  "aspect_ratio": "adaptive"
}
```

```json
  "video_urls": [
```

```json
  ],
  "seconds": "8",
  "aspect_ratio": "adaptive"

```

Specify what happens after the input clip, with an integer duration from 4 to 30 or `-1`.

### Create a draft

```json
{
  "model": "seedance-2.5",
  "draft": true,
  "resolution": "480p",
  "prompt": "A white cup rotates on a table under soft studio lighting. A smooth continuous shot.",
  "seconds": "6",
  "aspect_ratio": "16:9"
}
```

Wait for `completed` and inspect the draft before upgrading.

### Upgrade a draft

```json
{
  "model": "seedance-2.5",
  "output_format": "mov",
  "draft_task_id": "<DRAFT_TASK_ID>"
}
```

The final task gets a new ID and uses 1080p. Duration, ratio, seed, prompt, input media, audio and reference task type are inherited from the draft; do not send them again. You can set `output_format` and `watermark`; their defaults are `mp4` and `false`, and they do not inherit. Do not send `draft: true` for an upgrade.

Use a successful draft from the same account and model, created at most 7 days ago. A draft can be upgraded more than once; each upgrade is a separate billable task.

MOV is intended for editing. Some outputs require a player or editor that supports H.264 4:4:4 and PCM; use VLC, IINA or mpv if browser playback fails.
