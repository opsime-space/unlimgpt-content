Доступный публичный канал — [пакет UnlimGPT CLI в реестре npm](https://registry.npmjs.org/@unlimgpt%2fcli). Он выбирает исполняемый файл под поддерживаемую архитектуру macOS, Linux или Windows. До появления публичного standalone-выпуска используйте установку через менеджер пакетов.

## Установка

Проверьте опубликованную версию, затем установите пакет через npm:

```bash
npm view @unlimgpt/cli version
npm install --global @unlimgpt/cli
```

Для воспроизводимой установки добавьте проверенную версию к имени пакета. Менеджеру npm нужна собственная среда для установки и запуска пакета. У будущего standalone-файла будут другие шаги установки.

## Проверка

Выполните:

```text
unlimgpt --version
unlimgpt --help
```

Используйте только команды, которые показывает установленный выпуск. Если `configure` отсутствует, проверьте наличие новой версии пакета до работы с [руководством по клиенту](/ru/docs/getting-started/first-client).

## Обновление и удаление

Для обновления проверьте опубликованную версию и переустановите пакет. Для удаления выполните `npm uninstall --global @unlimgpt/cli`. Перед удалением выполните `unlimgpt logout`, если также хотите отозвать авторизацию CLI. API-ключи независимы: отзывайте их отдельно в [кабинете](/ru/api-keys) или командой `unlimgpt keys revoke`.
