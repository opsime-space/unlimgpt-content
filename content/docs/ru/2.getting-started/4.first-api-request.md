Задайте `BASE_URL` как корневой HTTPS-адрес API без завершающего `/` и без `/v1`, а `API_KEY` передайте из хранилища секретов. OpenAI-совместимые SDK используют `${BASE_URL}/v1`, Anthropic-совместимые — `BASE_URL`.

Нужен аккаунт UnlimGPT с доступом к API и кредитами. Проверка каталога бесплатна. Генерация может списать кредиты; сначала посмотрите [текущую ставку и баланс](/ru/docs/account/credits-and-limits).

## 1. Создайте и защитите ключ

Откройте [API-ключи](/ru/api-keys), создайте ключ организации с понятным именем, выберите срок действия, проверьте показанные права по умолчанию и сохраните значение в надёжном хранилище секретов. Не помещайте его в исходники, историю команд, URL и обращения в поддержку. Потерянный ключ замените новым и отзовите старый.

На [странице API-ключей](/ru/api-keys) скопируйте корневой адрес из поля базового URL для Anthropic. Если скопировали базовый URL для OpenAI, уберите завершающий `/v1`. Введите этот HTTPS-адрес без завершающего `/` в `BASE_URL`; тот же корень подходит для всех примеров, включая запросы изображений.

Для этой короткой проверки введите адрес, а затем ключ через скрытый ввод в той же оболочке, где запустите примеры. Не заменяйте ввод ключа командой с самим ключом. В Bash или Zsh:

~~~bash
printf 'Базовый URL API: '
read -r BASE_URL
export BASE_URL
printf 'Ключ API: '
read -rs API_KEY
printf '\n'
export API_KEY
~~~

В PowerShell 7.1 или новее:

~~~powershell
$env:BASE_URL = Read-Host "Базовый URL API"
$env:API_KEY = Read-Host "Ключ API UnlimGPT" -MaskInput
~~~

Обе переменные будут доступны дочерним процессам в этом сеансе терминала. Примеры для Bash/Zsh ниже передают заголовок авторизации curl через стандартный ввод; `-q` не даёт прочитать личные настройки curl. Не используйте общий терминал для проверки; после последнего запроса удалите переменную ключа.

## 2. Проверьте каталог без генерации

::code-group
#curl
~~~bash
printf 'Authorization: Bearer %s\n' "$API_KEY" \
  | curl -q -i -H @- "$BASE_URL/v1/models"
~~~
#typescript
~~~typescript
const baseUrl = process.env.BASE_URL;
if (!baseUrl) {
  throw new Error("BASE_URL is required");
}
const key = process.env.API_KEY;
if (!key) {
  throw new Error("API_KEY is required");
}

const response = await fetch(`${baseUrl}/v1/models`, {
  signal: AbortSignal.timeout(120_000),
  redirect: "error",
  headers: {
    Authorization: `Bearer ${key}`,
  },
});

console.log(response.status, response.headers.get("request-id"));

console.log(await response.text());
~~~
#python
~~~python
import os
import urllib.request


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, request, fp, code, msg, headers, newurl):
        return None


opener = urllib.request.build_opener(NoRedirect)

base_url = os.environ["BASE_URL"]
key = os.environ["API_KEY"]

request = urllib.request.Request(
    base_url + "/v1/models",
    headers={"Authorization": f"Bearer {key}"},
)

with opener.open(request, timeout=120) as response:
    print(response.status, response.headers.get("request-id"))
    print(response.read().decode("utf-8"))
~~~
#go
~~~go
package main

import (
	"fmt"
	"io"
	"net/http"
	"os"
	"time"
)

func main() {
	client := &http.Client{
		Timeout: 120 * time.Second,
		CheckRedirect: func(*http.Request, []*http.Request) error {
			return http.ErrUseLastResponse
		},
	}
	baseURL := os.Getenv("BASE_URL")
	if baseURL == "" {
		panic("BASE_URL is required")
	}
	key := os.Getenv("API_KEY")
	if key == "" {
		panic("API_KEY is required")
	}

	req, err := http.NewRequest(
		"GET",
		baseURL+"/v1/models",
		nil,
	)
	if err != nil {
		panic(err)
	}
	req.Header.Set("Authorization", "Bearer "+key)

	response, err := client.Do(req)
	if err != nil {
		panic(err)
	}

	fmt.Println(response.StatusCode, response.Header.Get("request-id"))
	if _, err := io.Copy(os.Stdout, response.Body); err != nil {
		panic(err)
	}
	response.Body.Close()
}
~~~
::

Ожидается HTTP 200 и массив `data` в JSON. У каждой модели есть канонический `id`; отображаемое имя нельзя подставлять вместо него. Пустой список или 403 — повод проверить доступ до платного запроса. Выберите `id`, который видит ваш ключ. Ниже используется `gpt-5.6-sol`; при необходимости замените его.

В PowerShell 7.1 или новее:

~~~powershell
$baseUrl = $env:BASE_URL
$parameters = @{
  Uri = "$baseUrl/v1/models"
  Headers = @{ Authorization = "Bearer $env:API_KEY" }
  SkipHttpErrorCheck = $true
}
$models = Invoke-WebRequest @parameters

$models.StatusCode
$models.Content | ConvertFrom-Json
~~~

## 3. Отправьте ограниченный запрос Responses

::code-group
#curl
~~~bash
printf 'Authorization: Bearer %s\n' "$API_KEY" \
  | curl -q -i -H @- "$BASE_URL/v1/responses" \
    -H "Content-Type: application/json" \
    -d '{
  "model": "gpt-5.6-sol",
  "input": "Ответь одним коротким предложением.",
  "max_output_tokens": 64,
  "stream": false,
  "store": false
}'
~~~
#typescript
~~~typescript
const baseUrl = process.env.BASE_URL;
if (!baseUrl) {
  throw new Error("BASE_URL is required");
}
const key = process.env.API_KEY;
if (!key) {
  throw new Error("API_KEY is required");
}

const response = await fetch(`${baseUrl}/v1/responses`, {
  signal: AbortSignal.timeout(120_000),
  redirect: "error",
  method: "POST",
  headers: {
    Authorization: `Bearer ${key}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-5.6-sol",
    input: "Ответь одним коротким предложением.",
    max_output_tokens: 64,
    stream: false,
    store: false,
  }),
});

console.log(response.status, response.headers.get("request-id"));

console.log(await response.text());
~~~
#python
~~~python
import json
import os
import urllib.request


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, request, fp, code, msg, headers, newurl):
        return None


opener = urllib.request.build_opener(NoRedirect)

base_url = os.environ["BASE_URL"]
key = os.environ["API_KEY"]

request = urllib.request.Request(
    base_url + "/v1/responses",
    headers={
        "Authorization": f"Bearer {key}",
        "Content-Type": "application/json",
    },
    data=json.dumps(
        {
            "model": "gpt-5.6-sol",
            "input": "Ответь одним коротким предложением.",
            "max_output_tokens": 64,
            "stream": False,
            "store": False,
        }
    ).encode("utf-8"),
)

with opener.open(request, timeout=120) as response:
    print(response.status, response.headers.get("request-id"))
    print(response.read().decode("utf-8"))
~~~
#go
~~~go
package main

import (
	"fmt"
	"io"
	"net/http"
	"os"
	"strings"
	"time"
)

func main() {
	client := &http.Client{
		Timeout: 120 * time.Second,
		CheckRedirect: func(*http.Request, []*http.Request) error {
			return http.ErrUseLastResponse
		},
	}
	baseURL := os.Getenv("BASE_URL")
	if baseURL == "" {
		panic("BASE_URL is required")
	}
	key := os.Getenv("API_KEY")
	if key == "" {
		panic("API_KEY is required")
	}

	req, err := http.NewRequest(
		"POST",
		baseURL+"/v1/responses",
		strings.NewReader(`{
  "model": "gpt-5.6-sol",
  "input": "Ответь одним коротким предложением.",
  "max_output_tokens": 64,
  "stream": false,
  "store": false
}`),
	)
	if err != nil {
		panic(err)
	}
	req.Header.Set("Authorization", "Bearer "+key)
	req.Header.Set("Content-Type", "application/json")

	response, err := client.Do(req)
	if err != nil {
		panic(err)
	}

	fmt.Println(response.StatusCode, response.Header.Get("request-id"))
	if _, err := io.Copy(os.Stdout, response.Body); err != nil {
		panic(err)
	}
	response.Body.Close()
}
~~~
::

Ожидаются HTTP 200, заголовок `request-id` и JSON с `status: "completed"`, ID вида `resp_…` и видимым ответом. Текст генерируется и может отличаться. В первом запросе явно указано `store: false`, поэтому позже получить его ответ по ID нельзя; безопасные метаданные активности и учёта всё равно сохраняются. Для повторяемого запроса приложения создайте и сохраните уникальный ключ по [руководству об идемпотентности](/ru/docs/api/idempotency-and-retries).

В PowerShell 7.1 или новее:

~~~powershell
$baseUrl = $env:BASE_URL
$payload = @{
  model = "gpt-5.6-sol"
  input = "Ответь одним коротким предложением."
  max_output_tokens = 64
  stream = $false
  store = $false
}
$body = $payload | ConvertTo-Json -Compress

$parameters = @{
  Method = "Post"
  Uri = "$baseUrl/v1/responses"
  Headers = @{ Authorization = "Bearer $env:API_KEY" }
  ContentType = "application/json; charset=utf-8"
  Body = $body
  SkipHttpErrorCheck = $true
}
$result = Invoke-WebRequest @parameters

$result.StatusCode
$result.Headers["request-id"]
$result.Content | ConvertFrom-Json
~~~

## 4. Проверьте исход операции

Откройте [активность API](/ru/api-activity) той же организации. Найдите недавнюю операцию по endpoint, времени и исходу. ID строки относится к запуску и отличается от HTTP-заголовка `request-id`. [Руководство по использованию](/ru/docs/account/usage) объясняет токены и списание на экране активности; не вычисляйте цену в деньгах из исхода. При ошибке передавайте поддержке только HTTP ID запроса и публичный код ошибки, без ключа и текста запроса. Следующий шаг есть в [справочнике ошибок](/ru/docs/api/errors-and-limits).

После проверки выполните `unset API_KEY` в Bash или Zsh либо `Remove-Item Env:API_KEY` в PowerShell. Это удалит переменную текущей оболочки; если ключ больше не нужен, отзовите его отдельно.
