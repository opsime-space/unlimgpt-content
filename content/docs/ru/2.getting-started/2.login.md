Вам нужны установленный [UnlimGPT CLI](/ru/docs/cli/install), доступ к нужной организации UnlimGPT, браузерная сессия и разблокированное системное хранилище секретов. Отдельный вход необязателен, если вы используете `unlimgpt configure`: эта команда при необходимости сама запустит авторизацию в браузере.

## Начните авторизацию

Выполните:

```text
unlimgpt login
```

Терминал покажет HTTPS-адрес и короткий код. Браузерная страница покажет `UnlimGPT CLI`, запрошенные разрешения, организацию и тот же код. Подтверждайте только запрос, который начали сами. Пока вы принимаете решение в браузере, не закрывайте терминал.

## Перед подтверждением

- Убедитесь, что код в браузере полностью совпадает с кодом в терминале.
- Отклоните код, который вы не запускали сами.
- Проверьте scopes: CLI может читать identity и управлять developer API-ключами, но не становится браузерной сессией.
- Ссылка с уже заполненным кодом никогда не подтверждает доступ автоматически.

Для SSH или компьютера без desktop-браузера используйте `unlimgpt login --no-browser` и откройте показанный HTTPS-адрес вручную.

## Проверьте результат

После подтверждения CLI сообщит об успешном входе. Проверьте пользователя и организацию без платного запроса к модели:

```text
unlimgpt whoami --json
```

Ответ содержит email аккаунта в `data.user.email` и ID организации в `data.organization.id`. Сверьте ID с организацией, выбранной в браузере. Обычная команда `unlimgpt whoami` печатает только email.

Если выбраны не те пользователь или организация, выполните `unlimgpt logout` и повторите вход с нужным браузерным аккаунтом. Если срок кода истёк или вы отклонили запрос, запустите `unlimgpt login` заново и получите новый код. Если браузер не открылся автоматически, используйте адрес, уже напечатанный в терминале. Если системное хранилище заблокировано или недоступно, разблокируйте либо настройте его до повтора: CLI не сохраняет refresh token в открытый файл.

Access token живёт в памяти несколько минут. Вращаемый refresh token хранится только в системном хранилище секретов. `unlimgpt logout` сначала отзывает авторизацию, затем удаляет локальный token; при сбое отзыва локальный token сохраняется для повторной попытки. Подробнее — в разделе [безопасности учётных данных](/ru/docs/security/credentials).

Далее [подключите первый клиент](/ru/docs/getting-started/first-client) и проверьте там реальный запрос.
