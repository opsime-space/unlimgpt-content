## Предварительные условия

- Установите [опубликованный пакет `@unlimgpt/cli`](/ru/docs/cli/install).
- При настройке CLI при необходимости откроет вход и создаст API-ключ; секрет останется в системном хранилище.

## Настройка

- Просмотрите поля YAML, которые изменятся: `unlimgpt configure continue --dry-run`.
- Примените конфигурацию: `unlimgpt configure continue`.
- Запускайте Continue через `unlimgpt launch continue -- cn --config ~/.continue/config.yaml`; IDE-расширение настраивается отдельно через его native secret UI.

## Проверка

- Запустите `unlimgpt launch continue -- cn --config ~/.continue/config.yaml`. Если настраивали `--profile work`, используйте `unlimgpt launch continue --profile work -- cn --config ~/.continue/config.yaml`, подставив своё имя профиля. Флаг `--config` открывает именно локальный YAML даже при сохранённом выборе другого конфига. В Continue CLI через `/model` выберите модель UnlimGPT, отправьте «Ответь одним словом: ГОТОВО», дождитесь непустого ответа и проверьте запрос в [Активности API](/ru/api-activity). Текст ответа может отличаться; запрос расходует кредиты.

## Ротация

- Сохраните ID старого ключа из `unlimgpt keys list`, затем создайте новый командой `unlimgpt keys create --name rotated-client`.
- Заново запустите клиент через UnlimGPT, выполните запрос и проверьте его в [Активности API](/ru/api-activity). Только после этого отзовите старый ключ.

## Отзыв

- Отзывайте ключ на [странице API-ключей](/ru/api-keys) после проверки нового подключения; это действие прекращает доступ старого ключа.

## Откат

- Запустите точную команду после `Undo:` в результате `configure`. CLI не перезапишет более поздние сторонние изменения.

## Устранение неполадок

| Проблема | Решение |
| --- | --- |
| В YAML используются anchors или directives. | CLI остановится без записи; выполните guided setup, чтобы не потерять семантику YAML. |
| IDE не видит переменную shell. | Это ожидаемо для расширения: сохраните ключ через native Continue UI/Hub, а не в `.env`. |

Если запрос не проходит, выполните `unlimgpt doctor --client continue` и откройте [руководство по диагностике](/ru/docs/troubleshooting/doctor). Диагностика не заменяет реальный запрос.

## Удаление

- Выполните guarded revert и удалите native secret в Continue UI, если создавали его для IDE.
