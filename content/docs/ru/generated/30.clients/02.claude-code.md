| Автоматическая настройка | `anthropic-messages` | Помощник Claude Code |

## Предварительные условия

- Установите [опубликованный пакет `@unlimgpt/cli`](/ru/docs/cli/install).
- При настройке CLI при необходимости откроет вход и создаст API-ключ; секрет останется в системном хранилище.

## Настройка

- Проверьте precedence и поля, которые изменятся: `unlimgpt configure claude-code --dry-run`.
- Примените конфигурацию: `unlimgpt configure claude-code`.
- CLI не записывает ключ в JSON: Claude Code получает его по `apiKeyHelper`.

## Проверка

- Откройте Claude Code, отправьте «Ответь одним словом: ГОТОВО», дождитесь непустого ответа и проверьте запрос в [Активности API](/ru/api-activity). Текст ответа может отличаться; запрос расходует кредиты.

## Ротация

- Сохраните ID старого ключа из `unlimgpt keys list`, затем создайте и выберите новый командой `unlimgpt keys create --name claude-code-next`.
- Отправьте запрос в Claude Code и проверьте его в [Активности API](/ru/api-activity); при необходимости перезапустите Claude Code. Только после успешного запроса отзовите старый ключ.

## Отзыв

- Отзывайте ключ на [странице API-ключей](/ru/api-keys) после проверки нового подключения; это действие прекращает доступ старого ключа.

## Откат

- Запустите точную команду после `Undo:` в результате `configure`. CLI не перезапишет более поздние сторонние изменения.

## Устранение неполадок

| Проблема | Решение |
| --- | --- |
| Helper не вызывается. | Удалите конфликтующий `ANTHROPIC_AUTH_TOKEN` или `ANTHROPIC_API_KEY` из более приоритетного окружения и повторите doctor. |
| Managed settings запрещают изменение. | Обратитесь к администратору; CLI не обходит managed policy. |

Если запрос не проходит, выполните `unlimgpt doctor --client claude-code` и откройте [руководство по диагностике](/ru/docs/troubleshooting/doctor). Диагностика не заменяет реальный запрос.

## Удаление

- Выполните guarded revert receipt; затем отзовите выделенный ключ Claude Code.
