## Предварительные условия

- Установите [опубликованный пакет `@unlimgpt/cli`](/ru/docs/cli/install).
- Установлен Cursor; в его настройках доступен OpenAI-совместимый адрес и поле API-ключа.

## Настройка

- Запустите `unlimgpt configure cursor` и откройте Settings → Models → API Keys.
- Сначала проверьте Cursor Local IDE в Ask: Agent с кастомным OpenAI endpoint не гарантирован, Cloud Agents не используют BYOK-ключи.
- Включите Use OpenAI API Key и Override OpenAI Base URL; введите точный model id без префикса.
- Для выбора effort добавьте к ID модели, показанному CLI, суффиксы `-effort-low` и `-effort-high` через Add Custom Model. Например: `gpt-6-sol-effort-low` и `gpt-6-sol-effort-high`.
- Штатный переключатель Reasoning в Cursor может не передавать reasoning_effort на кастомный Base URL; выбирайте нужный пункт модели.
- Скопируйте показанные Base URL и model id. CLI временно копирует API-ключ в буфер обмена.
- Вставьте API-ключ из буфера только в штатное поле секрета Cursor; CLI не читает SQLite или VS Code SecretStorage.

## Проверка

- Откройте Cursor, отправьте через настроенную модель «Ответь одним словом: ГОТОВО», дождитесь непустого ответа и проверьте запрос в [Активности API](/ru/api-activity). Текст может отличаться; запрос расходует кредиты.

## Ротация

- Сохраните ID старого ключа из `unlimgpt keys list`, создайте новый командой `unlimgpt keys create --name cursor-next` и повторите `unlimgpt configure cursor`: CLI скопирует новый ключ в буфер.
- Вставьте его в штатное поле секрета Cursor. Отправьте реальный запрос в Cursor и проверьте его в [Активности API](/ru/api-activity); только затем отзовите старый ключ на странице API-ключей.

## Отзыв

- Отзывайте ключ на [странице API-ключей](/ru/api-keys) после проверки нового подключения; это действие прекращает доступ старого ключа.

## Откат

- CLI не менял Cursor; удалите ключ и модель через его UI.

## Устранение неполадок

| Проблема | Решение |
| --- | --- |
| Нет поля custom endpoint. | Обновите Cursor и проверьте официальный OpenAI-compatible provider; CLI не автоматизирует скрытые внутренние форматы. |
| Запрос отклонён после setup. | Проверьте выбранный provider, Base URL и model id, затем выполните doctor. |

Если запрос не проходит, выполните `unlimgpt doctor --client cursor` и откройте [руководство по диагностике](/ru/docs/troubleshooting/doctor). Диагностика не заменяет реальный запрос.

## Удаление

- Удалите профиль UnlimGPT и secret через UI Cursor, затем отзовите выделенный API-ключ.
