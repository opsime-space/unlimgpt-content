## Предварительные условия

- Установите [опубликованный пакет `@unlimgpt/cli`](/ru/docs/cli/install).
- При настройке CLI при необходимости откроет вход и создаст API-ключ; секрет останется в системном хранилище.

## Настройка

- Для Codex CLI 0.156.1 настройте `gpt-6-sol`. Другие модели пока не поддерживаются этой командой.
- Просмотрите поля, которые изменятся, без записи: `unlimgpt configure codex --dry-run`.
- Закройте Codex Desktop. Если есть старые сеансы, после изменения `config.toml` CLI создаст резервную копию хранилищ сеансов в каталоге `backups` профиля Codex; она включает содержимое чатов. Храните её как личные данные.
- Примените owned-блок: `unlimgpt configure codex`.
- CLI добавит provider `unlimgpt`; секрет останется в системном хранилище и будет выдаваться через `auth.command`.

## Проверка

- Откройте Codex Desktop после настройки и проверьте, что старые чаты видны в списке.
- Начните новый чат в Codex, отправьте «Ответь одним словом: ГОТОВО», дождитесь непустого ответа и проверьте запрос в [Активности API](/ru/api-activity). Текст ответа может отличаться; запрос расходует кредиты.

## Ротация

- Сохраните ID старого ключа из `unlimgpt keys list`, затем создайте и выберите новый командой `unlimgpt keys create --name codex-next`.
- Отправьте запрос в Codex и проверьте его в [Активности API](/ru/api-activity); при необходимости перезапустите Codex. Только после успешного запроса отзовите старый ключ.

## Отзыв

- Отзывайте ключ на [странице API-ключей](/ru/api-keys) после проверки нового подключения; это действие прекращает доступ старого ключа.

## Откат

- Запустите точную команду после `Undo:` в результате `configure`. CLI не перезапишет более поздние сторонние изменения.

## Устранение неполадок

| Проблема | Решение |
| --- | --- |
| Codex не поддерживает `auth.command`. | Обновите Codex до версии с нативной provider-auth командой; plaintext fallback запрещён. |
| Активен другой provider. | Проверьте effective user-level `$CODEX_HOME/config.toml` и повторите `unlimgpt configure codex`. |

Если запрос не проходит, выполните `unlimgpt doctor --client codex` и откройте [руководство по диагностике](/ru/docs/troubleshooting/doctor). Диагностика не заменяет реальный запрос.

## Удаление

- Выполните guarded revert по receipt, затем отзовите отдельный ключ Codex, если он больше нигде не используется.
