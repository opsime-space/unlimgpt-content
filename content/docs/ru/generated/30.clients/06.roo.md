## Предварительные условия

- Установите [опубликованный пакет `@unlimgpt/cli`](/ru/docs/cli/install).
- Установлен Roo Code; в его настройках доступен OpenAI-совместимый адрес и поле API-ключа.

## Настройка

- Запустите `unlimgpt configure roo` и откройте Roo Code → API configuration profiles → OpenAI Compatible.
- Скопируйте показанные Base URL и model id. CLI временно копирует API-ключ в буфер обмена.
- Вставьте API-ключ из буфера только в штатное поле секрета Roo Code; CLI не читает SQLite или VS Code SecretStorage.

## Проверка

- Откройте Roo Code, отправьте через настроенную модель «Ответь одним словом: ГОТОВО», дождитесь непустого ответа и проверьте запрос в [Активности API](/ru/api-activity). Текст может отличаться; запрос расходует кредиты.

## Ротация

- Сохраните ID старого ключа из `unlimgpt keys list`, создайте новый командой `unlimgpt keys create --name roo-next` и повторите `unlimgpt configure roo`: CLI скопирует новый ключ в буфер.
- Вставьте его в штатное поле секрета Roo Code. Отправьте реальный запрос в Roo Code и проверьте его в [Активности API](/ru/api-activity); только затем отзовите старый ключ на странице API-ключей.

## Отзыв

- Отзывайте ключ на [странице API-ключей](/ru/api-keys) после проверки нового подключения; это действие прекращает доступ старого ключа.

## Откат

- CLI не менял Roo Code; удалите ключ и модель через его UI.

## Устранение неполадок

| Проблема | Решение |
| --- | --- |
| Нет поля custom endpoint. | Обновите Roo Code и проверьте официальный OpenAI-compatible provider; CLI не автоматизирует скрытые внутренние форматы. |
| Запрос отклонён после setup. | Проверьте выбранный provider, Base URL и model id, затем выполните doctor. |

Если запрос не проходит, выполните `unlimgpt doctor --client roo` и откройте [руководство по диагностике](/ru/docs/troubleshooting/doctor). Диагностика не заменяет реальный запрос.

## Удаление

- Удалите профиль UnlimGPT и secret через UI Roo Code, затем отзовите выделенный API-ключ.
