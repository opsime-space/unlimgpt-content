Установите [опубликованный пакет @unlimgpt/cli](/ru/docs/cli/install). Перед использованием команды проверьте установленную версию через `unlimgpt --version` и доступные команды через `unlimgpt --help`: справочник может описывать более новый выпуск.

## `login`

Войти через безопасное подтверждение кода в браузере.

```text
unlimgpt login [--no-browser] [--server <https-origin>]
```

## `logout`

Отозвать OAuth-сессию CLI и удалить локальный refresh token.

```text
unlimgpt logout
```

## `whoami`

Проверить текущего пользователя и организацию.

```text
unlimgpt whoami [--json]
```

## `models`

Показать полный доступный каталог моделей и их возможности.

```text
unlimgpt models [--json]
```

## `organizations`

Показать доступные организации или выбрать организацию текущего профиля.

```text
unlimgpt organizations <list [--json]|use <organization-id>>
```

## `keys`

Управлять API-ключами текущей организации. `keys permissions <key-id> --scope models:read --scope inference:write` заменяет набор прав; `--clear` снимает оба права, `--json` возвращает безопасные метаданные. `keys spend-limit <key-id> --micro-credits <amount>` задаёт общий бюджет ключа: 0 запрещает новые расходы, `--clear` снимает предел без сброса потраченных кредитов.

```text
unlimgpt keys <list|create|revoke|rotate|permissions|policy|spend-limit>
```

## `configure`

Настроить клиента или показать ручные шаги; `cloud` и `claude` — короткие алиасы `claude-code`.

```text
unlimgpt configure <client> [--profile <name>] [--model <id>] [--dry-run] [--yes]
```

## `revert`

Откатить owned-изменение, если файл не менялся после настройки.

```text
unlimgpt configure revert <receipt-id>
```

## `doctor`

Выполнить бесплатную диагностику; платная проба требует явного opt-in.

```text
unlimgpt doctor [--client <id>] [--json] [--probe --yes]
```

## `update`

Показать опубликованную версию. С --yes npm ставит именно её и не меняет профили, вход и API-ключи.

```text
unlimgpt update [--yes]
```

## `credential`

Выдать ключ только нативному credential helper через stdout.

```text
unlimgpt credential get --account <id> --kind api-key
```

## `launch`

Запустить дочерний процесс с эфемерным secret environment; `--profile` выбирает сохранённый профиль без переключения активного.

```text
unlimgpt launch <openai|anthropic|continue> [--profile <name>] -- <command> [args...]
```

## `clients`

Показать актуальную матрицу поддержки клиентов.

```text
unlimgpt clients [--json]
```

## `completion`

Сгенерировать completion для оболочки.

```text
unlimgpt completion <bash|zsh|fish|powershell>
```
