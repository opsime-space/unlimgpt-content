Сначала проверьте [совместимость клиентов](/ru/docs/reference/clients) и наличие `configure` в выводе `unlimgpt --help` установленного выпуска. Матрица совместимости показывает режим каждого клиента; пошаговое подключение требует изменений в настройках самого клиента. До применения плана проверьте доступ к нужной организации, работающее системное хранилище и конфигурацию самого клиента.

## Выберите режим настройки

Если у вас несколько организаций и установленный выпуск поддерживает команду
`organizations`, выберите организацию текущего профиля:

~~~text
unlimgpt organizations list
unlimgpt organizations use ORGANIZATION_ID
~~~

Выбор проверяется сервером. Смена организации сбрасывает выбранный ключ профиля,
но не отзывает прежние ключи и не удаляет их из системного хранилища. После смены
снова настройте клиент для нужной организации.

В **автоматическом** режиме CLI после подтверждения записывает только принадлежащие ему настройки клиента. **Безопасный запуск** передаёт credential дочернему процессу, не записывая его в конфигурационный файл. **Ручной** режим выдаёт шаги для интерфейса самого клиента; выполните их там. В любом режиме используйте [доступный вашему ключу ID модели](/ru/docs/api/models), а не отображаемое имя. Перед применением и откатом конфигурации Codex полностью закройте Codex Desktop.

## Предпросмотр и применение

~~~text
unlimgpt configure codex --dry-run
unlimgpt configure codex
~~~

Dry run не меняет файлы, секреты и вход. Он показывает место записи и каждое поле, которое будет добавлено, заменено или удалено. Нетронутые настройки в предпросмотр не попадают, прежнее значение заменяемого поля не печатается. План выбирает UnlimGPT в верхнеуровневом `model_provider` и заменяет верхнеуровневый `model`, сохраняя остальные настройки TOML. Команда применения может авторизовать через браузер, создать отдельный API-ключ и безопасно сохранить его, если в активном профиле нет пригодного ключа. Поддерживаемые настройки клиента она пишет только после подтверждения. Автоматические правки печатают receipts для осторожного отката; ручной режим выдаёт шаги и может попросить вставить ключ в штатное секретное поле клиента. Он не означает, что внешний клиент уже настроен. Копию в буфере обмена считайте секретом и очистите после настройки.

## Проверка и откат

Если установленный выпуск поддерживает `models`, сначала выполните `unlimgpt models`: это проверит доступ ключа без платной генерации. Затем откройте клиент и отправьте короткий запрос с [доступной моделью](/ru/docs/api/models). Он может списать кредиты; проверьте исход в [активности API](/ru/docs/account/usage). При проблеме с конфигурацией запустите [doctor](/ru/docs/troubleshooting/doctor). Для восстановления изменения, которым CLI ещё владеет:

~~~text
unlimgpt configure revert RECEIPT_ID
~~~

Используйте receipt из результата применения; у ручного режима без записи файла его нет. Откат откажется затирать более поздние чужие правки. Он не отзывает API-ключ, поэтому [проверьте его использование и отзовите отдельно](/ru/docs/cli/keys), если он больше не нужен. Неудачное применение могло уже создать ключ или receipt: до повтора проверьте безопасный вывод команды и [список ключей](/ru/api-keys). Сохраните сторонние настройки клиента и receipt. Далее: [жизненный цикл ключа](/ru/docs/cli/keys).
