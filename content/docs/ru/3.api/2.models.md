Задайте `BASE_URL` как корневой HTTPS-адрес API без завершающего `/` и без `/v1`, а `API_KEY` передайте из хранилища секретов. OpenAI-совместимые SDK используют `${BASE_URL}/v1`, Anthropic-совместимые — `BASE_URL`.

Список моделей зависит от организации, прав API-ключа и текущего каталога. Его чтение не запускает генерацию и не списывает кредиты. Вызывайте каталог при настройке клиента и обновляйте его перед выбором модели, если доступ мог измениться.

Список содержит object "list" и массив data. Выберите id записи, например gpt-5.6-sol, если он есть. Второй запрос вернёт карточку этой модели или HTTP 404, если она недоступна. Отображаемое имя предназначено для интерфейса; в запрос отправляется id. Каталог объявляет поддержку рассуждения, инструментов и поиска, но пока не содержит отдельных признаков для изображений, аудио и документов. Конкретный запрос также зависит от тарифа, протокола и текущей доступности исполнения.

## Что означают поля

| Поле | Как использовать |
| --- | --- |
| `id` | Идентификатор записи для `model` в запросе и конфигурации клиента. Выбирайте его из каталога, а не из отображаемого имени. |
| `display_name`, `description` | Подпись и пояснение для списка моделей в интерфейсе. Они могут меняться без смены `id`. |
| `is_default` | Подсказка для первоначального выбора в данной организации. Сохраняйте выбранный пользователем `id`, если он явно изменил модель. |
| `capabilities` | Объявляет `streaming`, `tools`, `reasoning`, `structuredOutput`, `jailbreak`, `webSearch`, `contextWindowTokens` и `defaultMaxOutputTokens`. Поддержку медиа эти поля не подтверждают; см. [рассуждение и медиа](/ru/docs/api/reasoning-and-media). |
| `created`, `created_at`, `owned_by`, `object`, `type` | Поля совместимости форматов каталогов OpenAI и Anthropic. Для выбора поддерживаемых возможностей используйте `capabilities`. |

Список также содержит `has_more: false`; если он пуст, `first_id` и `last_id` отсутствуют. Для выбора модели используйте элементы `data`, а не диапазон ID из этих полей. Возможности из каталога описывают модель, но фактический запрос дополнительно проверяет права тарифа и текущую доступность исполнения.

Если модель поддерживает Jailbreak, каталог также содержит запись с суффиксом `-jailbreak`, например `gpt-5.6-sol-jailbreak`. Это выбор той же модели с включённым Jailbreak при отказе. В этом режиме после отказа возможен ответ Jailbreak, если это разрешено вашим тарифом. Для обычного режима используйте базовый ID, например `gpt-5.6-sol`. Выбирайте дополнительный ID только тогда, когда он присутствует в каталоге; сам суффикс не открывает доступ.

## Если модель не появилась

1. Убедитесь, что клиент использует API-ключ нужной организации и право `models:read`. Браузерная сессия не заменяет Bearer-ключ в стороннем клиенте.
2. Сравните конфигурацию клиента с ответом каталога. Удалите старый ID из настроек, если запись больше не доступна.
3. Если `GET /v1/models` отвечает 401 или 403, исправьте [авторизацию](/ru/docs/api/authentication); повторять генерацию пока бессмысленно.
4. Если каталог доступен, но модель из старой конфигурации даёт 404 `model_not_found`, выберите другой `id` из текущего списка. Смена написания отображаемого имени не поможет.

Подставьте найденный ID в [первый запрос Responses](/ru/docs/getting-started/first-api-request). Если список пуст, проверьте [доступ и лимиты аккаунта](/ru/docs/account/credits-and-limits) до платного запроса. Для повторяемой настройки CLI используйте [`unlimgpt models`](/ru/docs/cli/reference).
