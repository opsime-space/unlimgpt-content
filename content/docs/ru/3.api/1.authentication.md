Задайте `BASE_URL` как корневой HTTPS-адрес API без завершающего `/` и без `/v1`, а `API_KEY` передайте из хранилища секретов. OpenAI-совместимые SDK используют `${BASE_URL}/v1`, Anthropic-совместимые — `BASE_URL`.

Создайте ключ организации в [API-ключах](/ru/api-keys), сохраните его полное значение при однократном показе и проверьте, что выбранной организации доступен API. Ключу нужны права для выбранной операции. Сессия браузера и OAuth-авторизация CLI отделены от API-ключа и не заменяют его при генерации. Держите секрет в системном хранилище или менеджере секретов; передавайте его только процессу, который делает вызов.

## Передайте ключ

Для OpenAI-совместимого клиента базовый адрес — `${BASE_URL}/v1`, ключ передаётся как Bearer token. Для Anthropic-совместимого клиента базовый адрес — `BASE_URL`, ключ передаётся в `x-api-key` вместе с `anthropic-version`. До примеров передайте `API_KEY` процессу из хранилища секретов. Не набирайте полное значение прямо в shell-команде: оно может остаться в истории.

#python
~~~python
import os
import urllib.request


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, request, fp, code, msg, headers, newurl):
        return None


opener = urllib.request.build_opener(NoRedirect)

base_url = os.environ["BASE_URL"]
key = os.environ["API_KEY"]

request = urllib.request.Request(
    base_url + "/v1/models",
    headers={"Authorization": f"Bearer {key}"},
)

with opener.open(request, timeout=120) as response:
    print(response.status, response.headers.get("request-id"))
    print(response.read().decode("utf-8"))

request = urllib.request.Request(
    base_url + "/v1/models",
    headers={"x-api-key": key, "anthropic-version": "2023-06-01"},
)

with opener.open(request, timeout=120) as response:
    print(response.status, response.headers.get("request-id"))
    print(response.read().decode("utf-8"))
~~~

#go
~~~go
package main

import (
	"fmt"
	"io"
	"net/http"
	"os"
	"time"
)

func main() {
	client := &http.Client{
		Timeout: 120 * time.Second,
		CheckRedirect: func(*http.Request, []*http.Request) error {
			return http.ErrUseLastResponse
		},
	}
	baseURL := os.Getenv("BASE_URL")
	if baseURL == "" {
		panic("BASE_URL is required")
	}
	key := os.Getenv("API_KEY")
	if key == "" {
		panic("API_KEY is required")
	}

	req, err := http.NewRequest(
		"GET",
		baseURL+"/v1/models",
		nil,
	)
	if err != nil {
		panic(err)
	}
	req.Header.Set("Authorization", "Bearer "+key)

	response, err := client.Do(req)
	if err != nil {
		panic(err)
	}

	fmt.Println(response.StatusCode, response.Header.Get("request-id"))
	if _, err := io.Copy(os.Stdout, response.Body); err != nil {
		panic(err)
	}
	response.Body.Close()
	req, err = http.NewRequest("GET", baseURL+"/v1/models", nil)
	if err != nil {
		panic(err)
	}
	req.Header.Set("x-api-key", key)
	req.Header.Set("anthropic-version", "2023-06-01")
	response, err = client.Do(req)
	if err != nil {
		panic(err)
	}

	fmt.Println(response.StatusCode, response.Header.Get("request-id"))
	if _, err := io.Copy(os.Stdout, response.Body); err != nil {
		panic(err)
	}
	response.Body.Close()
}
~~~

Оба запроса должны вернуть HTTP 200 и массив `data` с каталогом, доступным ключу. ID из каталога можно передавать в запросах генерации. Код 401 означает отсутствие, ошибку или истечение срока ключа; проверьте передачу значения процессу, не печатая его. Код 403 означает недостаточный доступ организации или права. Проверьте выбранную организацию и метаданные ключа до платного вызова; публичные коды разобраны в [ошибках и лимитах](/ru/docs/api/errors-and-limits).

## Сверьте право с операцией

| Операция | Необходимое право | Проверка без генерации |
| --- | --- | --- |
| `GET /v1/models`, `GET /v1/models/{model}` | `models:read` | Вызов каталога выше. |
| Responses, Chat Completions, Messages и работа с сохранёнными беседами | `inference:write` | Посмотрите права ключа в [кабинете](/ru/api-keys); запрос генерации может списать кредиты. |

Один ключ может использоваться в обеих протокольных семьях, если его права и организация допускают соответствующую операцию. Не выдавайте общий ключ всей команде: отдельный ключ на приложение или окружение упрощает отзыв и расследование. Если операции нужны только для чтения каталога, не расширяйте право до генерации ради удобства.

## Сохраните границу доступа

Не помещайте ключ в URL, Git-конфигурацию, query браузера, скриншот или обращение в поддержку. Не записывайте полные заголовки запросов в логи приложения. При раскрытии отзовите ключ в [кабинете](/ru/api-keys), создайте замену и обновите каждый использовавший его клиент. Отзыв ключа не завершает сессию браузера и доступ CLI. Эти отдельные действия описаны в [безопасности аккаунта](/ru/docs/account/security).

При замене сначала создайте новый ключ, проверьте бесплатный каталог и один разрешённый вызов новым процессом, затем переключите клиентов и отзовите старый. Если старый ключ уже раскрыт, отзовите его немедленно и восстановите подключение новым. Полное значение после однократного показа не восстанавливается из кабинета.
