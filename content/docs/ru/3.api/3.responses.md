Задайте `BASE_URL` как корневой HTTPS-адрес API без завершающего `/` и без `/v1`, а `API_KEY` передайте из хранилища секретов. OpenAI-совместимые SDK используют `${BASE_URL}/v1`, Anthropic-совместимые — `BASE_URL`.

Responses — основная OpenAI-совместимая поверхность генерации. Нужны [API-ключ](/ru/docs/api/authentication), доступный [ID модели](/ru/docs/api/models) и кредиты. Генерация может списать кредиты.

## Отправьте запрос

::code-group
#curl
~~~bash
printf 'Authorization: Bearer %s\n' "$API_KEY" \
  | curl -q -H @- -i "$BASE_URL/v1/responses" \
    -H "Content-Type: application/json" \
    -d '{
  "model": "gpt-5.6-sol",
  "input": "Ответь одним коротким предложением.",
  "max_output_tokens": 64,
  "stream": false,
  "store": true
}'
~~~
#typescript
~~~typescript
const baseUrl = process.env.BASE_URL;
if (!baseUrl) {

  method: "POST",
  headers: {

  },

    model: "gpt-5.6-sol",

    max_output_tokens: 64,
    stream: false,
    store: true,
  }),
});

console.log(response.status, response.headers.get("request-id"));

console.log(await response.text());
~~~
#python
~~~python
import json
import os
import urllib.request


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, request, fp, code, msg, headers, newurl):
        return None


opener = urllib.request.build_opener(NoRedirect)

base_url = os.environ["BASE_URL"]
key = os.environ["API_KEY"]

request = urllib.request.Request(
    base_url + "/v1/responses",
    headers={
        "Authorization": f"Bearer {key}",
        "Content-Type": "application/json",
    },
    data=json.dumps(
        {
            "model": "gpt-5.6-sol",
            "input": "Ответь одним коротким предложением.",
            "max_output_tokens": 64,
            "stream": False,
            "store": True,
        }
    ).encode("utf-8"),
)

with opener.open(request, timeout=120) as response:
    print(response.status, response.headers.get("request-id"))
    print(response.read().decode("utf-8"))
~~~
#go
~~~go
package main

import (
	"fmt"
	"io"
	"net/http"
	"os"
	"strings"
	"time"
)

func main() {
	client := &http.Client{
		Timeout: 120 * time.Second,
		CheckRedirect: func(*http.Request, []*http.Request) error {
			return http.ErrUseLastResponse
		},
	}
	baseURL := os.Getenv("BASE_URL")
	if baseURL == "" {
		panic("BASE_URL is required")
	}
	key := os.Getenv("API_KEY")
	if key == "" {
		panic("API_KEY is required")
	}

	req, err := http.NewRequest(
		"POST",
		baseURL+"/v1/responses",
		strings.NewReader(`{
  "model": "gpt-5.6-sol",
  "input": "Ответь одним коротким предложением.",
  "max_output_tokens": 64,
  "stream": false,
  "store": true
}`),
	)
	if err != nil {
		panic(err)
	}
	req.Header.Set("Authorization", "Bearer "+key)
	req.Header.Set("Content-Type", "application/json")

	response, err := client.Do(req)
	if err != nil {
		panic(err)
	}

	fmt.Println(response.StatusCode, response.Header.Get("request-id"))
	if _, err := io.Copy(os.Stdout, response.Body); err != nil {
		panic(err)
	}
	response.Body.Close()
}
~~~
::

Успешный ответ без потока содержит id, model, status, output и usage. Текст генерации может отличаться. Сохраните HTTP-заголовок `request-id` для поддержки без передачи текста. [Активность API](/ru/api-activity) показывает исходы недавних запусков; ID строки отличается от этого заголовка. Сохранённый ответ можно прочитать через GET /v1/responses/{id} с ключом той же организации. Если указать store: false и не привязать беседу, чтение недоступно.

## Прочитайте результат

Ниже пример формы успешного ответа. ID, текст и числа токенов вашего вызова будут другими:

~~~json
{
  "id": "resp_018f3f407b447cc4b8ba3f62656c299c",
  "object": "response",
  "created_at": 1790244000,
  "status": "completed",
  "incomplete_details": null,
  "model": "gpt-5.6-sol",
  "output": [{
    "id": "msg_018f3f407b447cc4b8ba3f62656c299c",
    "type": "message",
    "role": "assistant",
    "status": "completed",
    "content": [{ "type": "output_text", "text": "Готово.", "annotations": [] }]
  }],
  "output_text": "Готово.",
  "usage": {
    "input_tokens": 12,
    "input_tokens_details": { "cached_tokens": 0 },
    "output_tokens": 5,
    "output_tokens_details": { "reasoning_tokens": 0 },
    "total_tokens": 17
  }
}
~~~

Сначала проверьте `status`. Для простого текстового ответа можно читать `output_text`; для инструмента, цитат или нескольких блоков обрабатывайте массив `output` по типу каждого элемента. `usage` описывает токены протокола. Окончательное списание в кредитах смотрите в [активности API](/ru/docs/account/usage); не вычисляйте цену в деньгах только из `total_tokens`. При `status: incomplete` проверьте `incomplete_details.reason` и не выдавайте частичный текст за завершённый ответ.

## Прочитайте сохранённый ответ

Используйте `id` из завершённого JSON-ответа. Пример cURL запросит его в терминале; для TypeScript, Python или Go задайте `UNLIMGPT_RESPONSE_ID` в окружении. Чтение не запускает новую генерацию:

::code-group
#curl
~~~bash
printf 'ID ответа: '
read -r UNLIMGPT_RESPONSE_ID
printf 'Authorization: Bearer %s\n' "$API_KEY" \
  | curl -q -H @- -i "$BASE_URL/v1/responses/$UNLIMGPT_RESPONSE_ID"
~~~

HTTP 200 возвращает сохранённый ответ с `id`, `status`, `output` и `usage`; проверьте, что `id` совпадает с введённым. Для неизвестного, удалённого или недоступного ответа возвращается 404. В запросе выше явно задано `store: true`; при `store: false` ответ без сохранения прочитать нельзя.

## Сохранение и повтор

`id` из тела нужен для чтения сохранённого ответа и явной отмены; `request-id` из HTTP-заголовка нужен для поддержки. `GET /v1/responses/{id}` требует ключ той же организации. Продолжение через `previous_response_id` сейчас не поддерживается: передавайте нужную историю в новом `input`. После сетевого обрыва повторяйте логический запрос с прежним `Idempotency-Key` по [руководству о повторах](/ru/docs/api/idempotency-and-retries).

Для вывода по мере генерации откройте [потоки](/ru/docs/api/streaming).
