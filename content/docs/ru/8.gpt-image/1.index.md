GPT Image готовится к запуску. Доступные версии моделей, параметры, цены и примеры запросов появятся здесь вместе с открытием доступа.

## Подготовьте материалы

Для нового изображения опишите сюжет, композицию, стиль, освещение и точный текст, который должен быть на картинке. Для редактирования подготовьте исходный файл и перечислите, что нужно изменить и что сохранить.

Не отправляйте запросы с ID модели или параметрами из стороннего руководства, пока они не подтверждены для вашего подключения.

Для анализа готового изображения используйте [чат-модель с поддержкой медиа](/ru/docs/api/reasoning-and-media).
