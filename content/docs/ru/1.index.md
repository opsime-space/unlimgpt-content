Задайте `BASE_URL` как корневой HTTPS-адрес API без завершающего `/` и без `/v1`, а `API_KEY` передайте из хранилища секретов. OpenAI-совместимые SDK используют `${BASE_URL}/v1`, Anthropic-совместимые — `BASE_URL`.

Для чата и API используется один аккаунт; доступ к API определяется тарифом и правами ключа. Укажите в настройках клиента **базовый адрес его протокола**, а не URL отдельного запроса:

| Клиент или протокол | Базовый адрес | Что вызывает клиент |
| --- | --- | --- |
| OpenAI Responses и Chat Completions | `${BASE_URL}/v1` | `/responses` или `/chat/completions` |
| Anthropic Messages | `BASE_URL` | `/v1/messages` |

Полный ключ передавайте только штатным способом клиента; не добавляйте его к адресу. [Матрица совместимости](/ru/docs/reference/clients) показывает точный режим настройки каждого AI-клиента.

## Минимальный запрос Responses

После [создания API-ключа](/ru/docs/account/api-keys) задайте `API_KEY` в оболочке из защищённого хранилища. Выберите ID модели из бесплатного [каталога](/ru/docs/api/models) и замените ID в примере, если ваша организация видит другую модель. Этот запрос может списать кредиты.

::code-group
#curl
~~~bash
printf 'Authorization: Bearer %s\n' "$API_KEY" \
  | curl -q -H @- "$BASE_URL/v1/responses" \
    -H "Content-Type: application/json" \
    -d '{
  "model": "gpt-5.6-sol",
  "input": "Ответь одним коротким предложением.",
  "max_output_tokens": 64,
  "stream": false,
  "store": false
}'
~~~
#typescript
~~~typescript
const baseUrl = process.env.BASE_URL;
if (!baseUrl) {
  throw new Error("BASE_URL is required");
}
const key = process.env.API_KEY;
if (!key) {
  throw new Error("API_KEY is required");
}

const response = await fetch(`${baseUrl}/v1/responses`, {
  signal: AbortSignal.timeout(120_000),
  redirect: "error",
  method: "POST",
  headers: {
    Authorization: `Bearer ${key}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-5.6-sol",
    input: "Ответь одним коротким предложением.",
    max_output_tokens: 64,
    stream: false,
    store: false,
  }),
});

console.log(response.status, response.headers.get("request-id"));

console.log(await response.text());
~~~
#python
~~~python
import json
import os
import urllib.request


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, request, fp, code, msg, headers, newurl):
        return None


opener = urllib.request.build_opener(NoRedirect)

base_url = os.environ["BASE_URL"]
key = os.environ["API_KEY"]

request = urllib.request.Request(
    base_url + "/v1/responses",
    headers={
        "Authorization": f"Bearer {key}",
        "Content-Type": "application/json",
    },
    data=json.dumps(
        {
            "model": "gpt-5.6-sol",
            "input": "Ответь одним коротким предложением.",
            "max_output_tokens": 64,
            "stream": False,
            "store": False,
        }
    ).encode("utf-8"),
)

with opener.open(request, timeout=120) as response:
    print(response.status, response.headers.get("request-id"))
    print(response.read().decode("utf-8"))
~~~
#go
~~~go
package main

import (
	"fmt"
	"io"
	"net/http"
	"os"
	"strings"
	"time"
)

func main() {
	client := &http.Client{
		Timeout: 120 * time.Second,
		CheckRedirect: func(*http.Request, []*http.Request) error {
			return http.ErrUseLastResponse
		},
	}
	baseURL := os.Getenv("BASE_URL")
	if baseURL == "" {
		panic("BASE_URL is required")
	}
	key := os.Getenv("API_KEY")
	if key == "" {
		panic("API_KEY is required")
	}

	req, err := http.NewRequest(
		"POST",
		baseURL+"/v1/responses",
		strings.NewReader(`{
  "model": "gpt-5.6-sol",
  "input": "Ответь одним коротким предложением.",
  "max_output_tokens": 64,
  "stream": false,
  "store": false
}`),
	)
	if err != nil {
		panic(err)
	}
	req.Header.Set("Authorization", "Bearer "+key)
	req.Header.Set("Content-Type", "application/json")

	response, err := client.Do(req)
	if err != nil {
		panic(err)
	}

	fmt.Println(response.StatusCode, response.Header.Get("request-id"))
	if _, err := io.Copy(os.Stdout, response.Body); err != nil {
		panic(err)
	}
	response.Body.Close()
}
~~~
::

Ответ содержит `id`, `status`, `model`, `output_text`, структурированный `output` и `usage`. Текст доступен также в блоке `output[].content[]` с типом `output_text`. Пример явно отключает сохранение ответа для чтения по ID; метаданные активности всё равно записываются. Проверьте endpoint, время и исход недавней операции в [активности API](/ru/api-activity). ID строки отличается от HTTP-заголовка `request-id`. Перед отправкой откройте [пошаговое руководство](/ru/docs/getting-started/first-api-request).
