## Возможности Seedance

Таблица описывает формы запросов, которые принимают модели. Доступность
расширенных режимов зависит от выданного подключения и ключа; проверьте её
до создания потенциально платной задачи.

| Сценарий | Возможности модели |
|---|---|
| Текст → видео | Поддерживается |
| Изображение → видео | Первый кадр, первый и последний кадры либо набор референсов; Mini/Fast требуют текст; аудиореференсу также нужно изображение или видео |
| Несколько референсных изображений | До 9 для 2.0/Mini/Fast и до 30 для 2.5 |
| Видеореференсы | До 3 для 2.0/Mini/Fast и до 10 для 2.5 |
| Аудиореференсы | В 2.5 — отдельно и вместе с изображениями/видео; в 2.0/Mini/Fast — вместе с изображением или видео |
| Изображения + видео + аудио | Поддерживаются в одном запросе |
| Редактирование и продолжение видео | Seedance 2.5: `omni_reference_task_type: "edit"` / `"extend"` |
| Черновик и финальная версия | Seedance 2.5: `draft: true`, затем `draft_task_id` |
| Выходной звук через `generate_audio` | Можно включить; точность речи и синхронизации зависит от результата генерации |
| Формат результата | MP4; Seedance 2.5 также поддерживает MOV |

Передавайте HTTPS-ссылки в расширениях `image_urls`, `video_urls` и `audio_urls`.
Для ролей изображения используйте `image_with_roles: [{"url":"REFERENCE_URL","role":"first_frame"}]`;
роли — `reference_image`, `first_frame` и `last_frame`. Multipart-загрузка
видео не поддерживается. Первый/последний
кадр нельзя смешивать с `reference_image`. У 2.5 кадры можно сочетать с видео
или аудио, у остальных моделей — нельзя. В тексте объясните назначение каждого референса.

В режиме референсов Seedance 2.0, Mini и Fast принимают до 9 изображений,
3 видео и 3 аудио; Seedance 2.5 — до 30 изображений, 10 видео и 10 аудио.
Видео для серии 2.0 длится
2–15 секунд (суммарно не более 15), видео 2.5 — 2–30 секунд (суммарно не
более 30). Для аудио действуют те же интервалы и суммарные пределы.
Для редактирования в 2.5 исходный ролик должен длиться 4–30 секунд.

### Требования к входным файлам

| Материал | Формат и размер |
|---|---|
| Изображение | JPEG, PNG, WebP, BMP, TIFF, GIF, HEIC или HEIF; меньше 30 МБ |
| Видео | MP4 или MOV; до 200 МБ; 24–60 кадров/с |
| Аудио | WAV или MP3; до 15 МБ |

Для изображений и видео ширина и высота должны находиться в пределах
300–6000 пикселей, отношение ширины к высоте — от 0,4 до 2,5.
Для видео дополнительно требуется от 407 696 до 8 295 044 пикселей в кадре.
В MP4 используйте видео H.264/AVC или H.265/HEVC и звук AAC или MP3;
в MOV дополнительно допускается PCM. Расширение файла само по себе
не подтверждает подходящий контейнер и кодек.

В примерах используются прямые публичные HTTPS-ссылки на файлы.
Сервис должен получить их без входа в аккаунт, cookie и дополнительных
заголовков авторизации. Локальные пути и ссылки на страницы просмотра
не подходят. Суммарные пределы видео и аудио проверяются отдельно.

Генерация может занимать несколько минут. Ожидайте итогового статуса,
сохранив ID задачи. Срок завершения отдельной задачи не гарантируется.

`generate_audio: true` создаёт выходной звук и не является передачей
аудиореференса; это разные настройки.

`resolution` задаёт выбранный режим. Фактические размеры готового файла могут
отличаться, особенно при `aspect_ratio: "adaptive"`; проверяйте их после скачивания.

## Примеры с референсами

Замените ссылки `REFERENCE_____URL` в примерах на прямые
HTTPS-ссылки на свои файлы.

### Изображение как референс

```json
{
  "model": "seedance-2.5",
  "resolution": "720p",
  "generate_audio": true,
  "prompt": "Animate the landscape in the image. Preserve the house, mountain outlines, shoreline and colors. The camera smoothly moves forward, water ripples gently and clouds drift slowly. One continuous shot, no location changes or captions.",
  "image_with_roles": [
    {
      "url": "REFERENCE_REFERENCE_JPG_URL",
      "role": "reference_image"
    }
  ],
  "seconds": "30",
  "aspect_ratio": "adaptive"
}
```

Сохраните это тело как `request.json` и используйте те же создание, polling
и скачивание. Каждый новый `POST` — отдельная потенциально оплачиваемая задача.

`adaptive` полезен, когда нужно сохранить пропорции изображения. При этом
ширина готового видео может отличаться от стандартного кадра 1280×720.

### Два изображения: предмет и окружение

В этом примере первое изображение задаёт предмет, второе — сцену.
Замените обе ссылки на свои доступные изображения.

```json
{
  "model": "seedance-2.5",
  "resolution": "720p",
  "generate_audio": false,
  "prompt": "Use the vase shape and color from the first image and the room from the second. The vase stands on a table in this room. The camera slowly moves closer. Preserve the object and interior, no captions.",
  "image_with_roles": [
    {
      "url": "REFERENCE_PRODUCT_JPG_URL",
      "role": "reference_image"
    },
    {
      "url": "REFERENCE_ROOM_JPG_URL",
      "role": "reference_image"
    }
  ],
  "seconds": "10",
  "aspect_ratio": "16:9"
}
```

Все изображения здесь имеют роль `reference_image`. Порядок массива должен
совпадать с описанием в тексте; результат совмещения оценивайте по готовому ролику.

### Первый и последний кадры

`first_frame` задаёт начало, `last_frame` — финал. Передавайте не более одного
изображения на каждую роль; `last_frame` требует `first_frame`.
Используйте `aspect_ratio: "adaptive"`: пропорции задаёт первый кадр.
Заранее обрежьте или дополните его до нужных пропорций.

```json
{
  "model": "seedance-2.5",
  "resolution": "720p",
  "prompt": "The camera smoothly moves from the door to the window. Preserve the interior and lighting, without abrupt scene cuts.",
  "image_with_roles": [
    {
      "url": "REFERENCE_FIRST_JPG_URL",
      "role": "first_frame"
    },
    {
      "url": "REFERENCE_LAST_JPG_URL",
      "role": "last_frame"
    }
  ],
  "seconds": "8",
  "aspect_ratio": "adaptive"
}
```

Если нужен только первый кадр, удалите элемент `last_frame`.

### Видеореференс

```json
{
  "model": "seedance-2.5",
  "omni_reference_task_type": "reference",
  "resolution": "720p",
  "generate_audio": false,
  "prompt": "Use the camera movement and pacing from @Video1. Create a new scene with a red bicycle on a city street.",
  "video_urls": [
    "REFERENCE_CAMERA_MP4_URL"
  ],
  "seconds": "12",
  "aspect_ratio": "16:9"
}
```

### Только аудиореференс (Seedance 2.5)

Текст с аудио можно передать, но он не обязателен. В Seedance 2.0, Mini и Fast к аудио
добавьте хотя бы изображение или видео.

```json
{
  "model": "seedance-2.5",
  "omni_reference_task_type": "reference",
  "resolution": "720p",
  "generate_audio": true,
  "audio_urls": [
    "REFERENCE_MUSIC_MP3_URL"
  ],
  "seconds": "10",
  "aspect_ratio": "16:9"
}
```

### Изображение, видео и аудио вместе

Референсы разных типов можно объединить. Их порядок соответствует ссылкам
`@Image1`, `@Video1`, `@Audio1` в описании.
Для смешанных референсов указывайте `omni_reference_task_type: "reference"`
и `aspect_ratio: "adaptive"`; опишите новую сцену с использованием этих материалов.

```json
{
  "model": "seedance-2.5",
  "omni_reference_task_type": "reference",
  "resolution": "720p",
  "generate_audio": true,
  "prompt": "Create a new scene: the character from @Image1 walks along the waterfront. Use camera movement from @Video1 and the rhythm of @Audio1. One continuous shot.",
  "image_with_roles": [
    {
      "url": "REFERENCE_CHARACTER_PNG_URL",
      "role": "reference_image"
    }
  ],
  "video_urls": [
    "REFERENCE_MOTION_MP4_URL"
  ],
  "audio_urls": [
    "REFERENCE_RHYTHM_MP3_URL"
  ],
  "seconds": "12",
  "aspect_ratio": "adaptive"
}
```

### Смешанные референсы, 30 секунд, 720p

Этот вариант задаёт длинную новую сцену. Подставьте свои изображение,
видеоролик и аудиофайл, соблюдая [пределы входных материалов](#требования-к-входным-файлам).

```json
{
  "model": "seedance-2.5",
  "omni_reference_task_type": "reference",
  "resolution": "720p",
  "generate_audio": true,
  "watermark": false,
  "output_format": "mp4",
  "prompt": "Create a new 30-second scene. The object from @Image1 stands on a table by a window. For the first 10 seconds the camera moves closer, for the next 10 it orbits the object, and for the last 10 it gently stops. Use the camera movement style from @Video1 and the rhythm of @Audio1. Preserve the object shape and lighting, no captions.",
  "image_with_roles": [
    {
      "url": "REFERENCE_PRODUCT_PNG_URL",
      "role": "reference_image"
    }
  ],
  "video_urls": [
    "REFERENCE_CAMERA_MP4_URL"
  ],
  "audio_urls": [
    "REFERENCE_RHYTHM_WAV_URL"
  ],
  "seconds": "30",
  "aspect_ratio": "adaptive"
}
```

### Редактирование исходного видео

Для 2.5 укажите `edit`, `aspect_ratio: "adaptive"` и `seconds: "-1"`. Текст описывает
изменение исходного видео, например цвет предмета или звуковую дорожку.

```json
{
  "model": "seedance-2.5",
  "omni_reference_task_type": "edit",
  "resolution": "720p",
  "prompt": "In @Video1 change the car color to dark green, preserving its motion, camera angle and scene duration.",
  "video_urls": [
    "REFERENCE_ORIGINAL_MP4_URL"
  ],
  "seconds": "-1",
  "aspect_ratio": "adaptive"
}
```

### Продолжение видео

Для 2.5 укажите `extend` и `aspect_ratio: "adaptive"`. Опишите, что должно
произойти после исходного ролика; длительность задайте целым числом от 4 до 30
или предоставьте выбор модели через `-1`.

```json
{
  "model": "seedance-2.5",
  "omni_reference_task_type": "extend",
  "resolution": "720p",
  "prompt": "Continue @Video1 forward: the cyclist crosses the intersection and turns into a park. Preserve the character, lighting and camera movement.",
  "video_urls": [
    "REFERENCE_OPENING_MP4_URL"
  ],
  "seconds": "8",
  "aspect_ratio": "adaptive"
}
```

### MOV и черновик

Для монтажа задайте `output_format: "mov"`. Черновик Seedance 2.5 создавайте
с `draft: true` и `resolution: "480p"`:

```json
{
  "model": "seedance-2.5",
  "draft": true,
  "resolution": "480p",
  "prompt": "A white cup rotates on a table under soft studio lighting. A smooth continuous shot.",
  "seconds": "6",
  "aspect_ratio": "16:9"
}
```

Дождитесь `completed` у черновика и оцените результат. Затем создайте
финальную задачу, подставив его `id`; она получит новый ID и разрешение `1080p`:

```json
{
  "model": "seedance-2.5",
  "output_format": "mov",
  "draft_task_id": "<ID_ЧЕРНОВИКА>"
}
```

Во второй запрос не повторяйте `seconds`, `aspect_ratio`, `seed`, текст, исходные
файлы, `generate_audio` и `omni_reference_task_type`: они наследуются от черновика.
Можно заново задать `output_format` и `watermark`.
Если их не указать, используются `mp4` и `false`; значения этих
двух полей не наследуются. Не передавайте `draft: true` при создании
финальной версии.

Используйте черновик того же аккаунта и той же модели, созданный не более
7 дней назад. Один завершённый черновик можно использовать для нескольких
финальных версий; каждая из них является отдельным платным заказом.

MOV предназначен для монтажа. Для воспроизведения H.264 4:4:4 и PCM используйте
редактор или плеер с поддержкой этих форматов, например VLC, IINA или mpv,
если браузер не воспроизводит файл.
