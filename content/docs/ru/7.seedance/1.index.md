Для Seedance используйте OpenAI Videos API: `POST /v1/videos` с `model`, `prompt`, `seconds` и `size`. Доступность модели и референсов зависит от подключения и API-ключа. Успешный ответ на создание возвращает ID задачи, а не готовое видео.

## Быстрый старт

Задайте `BASE_URL` и `API_KEY` по инструкции [Подключение](/ru/docs/seedance/connect). Сохраните `request.json`:

```json
{
  "model": "seedance-2.5",
  "size": "1280x720",
  "prompt": "A paper boat glides across a quiet lake at sunrise, one continuous shot.",
  "seconds": "5"
}
```

Создайте задачу один раз и сохраните `id`:

```bash
curl --fail --silent --show-error --max-time 120 "$BASE_URL/v1/videos" -H "Authorization: Bearer $API_KEY" -H 'Content-Type: application/json' --data-binary @request.json -o created.json
jq -r '.id' created.json
```

Читайте `GET /v1/videos/{id}` до `completed` или `failed`. После успеха скачайте файл через `/v1/videos/{id}/content` с API-ключом либо по необязательному подписанному `content.video_url` без API-ключа; см. [Результаты](/ru/docs/seedance/results). Сохраните ID перед продолжением, чтобы перезапуск не создал новую платную задачу.

## Операции

| Назначение | Метод и путь | Авторизация |
|---|---|---|
| Создать задачу Seedance | `POST /v1/videos` | API Bearer |
| Прочитать ту же задачу | `GET /v1/videos/{id}` | API Bearer |
| Скачать видео | `GET /v1/videos/{id}/content` | API Bearer |
| Скачать по подписанной ссылке | `GET` по точному HTTPS URL из `content` или `Location` | Без API Bearer |

Статусы чтения задачи: `queued`, `in_progress`, `completed`, `failed`. Неизвестный статус не считается успехом.
