## Модели

| Модель | ID | Длительность | Разрешение |
|---|---|---|---|---|
| Seedance 2.0 | `seedance-2.0` | 4–15 с | `480p`, `720p`, `1080p`, `4K` |
| Seedance 2.5 | `seedance-2.5` | 4–30 с или `-1` | `480p`, `720p`, `1080p` |
| Seedance 2.0 Mini | `seedance-2.0-mini` | 4–15 с | `480p`, `720p` |
| Seedance 2.0 Fast | `seedance-2.0-fast` | 4–15 с | `480p`, `720p` |

Все четыре модели принимают текст без референсов. Mini/Fast требуют текст и при добавлении референсов; 2.0/2.5 также поддерживают референсные медиа в предусмотренных режимах.

В `model` укажите точный публичный ID; доступность определяется ключом. Явно задавайте `seconds`. Для горизонтального или вертикального 720p используйте `size`; другие разрешения и пропорции задаются расширениями `resolution` и `aspect_ratio`. Модельные поля ниже — расширения формата OpenAI Videos; доступ к ним зависит от подключения.

## Поля запроса

| Поле | Значение |
|---|---|
| `model` | Точный ID из таблицы |
| `prompt` | Текстовое описание; Mini/Fast требуют текст; Fast — до 4000 символов |
| `size` | `1280x720` либо `720x1280` для горизонтального или вертикального 720p |
| `seconds` | Строка с целым числом в диапазоне модели; `"-1"` — расширение для автоматической длительности у 2.5 |
| `resolution` | Расширение: разрешение из таблицы модели; при наличии `size` значения должны совпадать |
| `aspect_ratio` | `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9`, `adaptive`; при наличии `size` значения должны совпадать |
| `generate_audio` | Boolean, по умолчанию `true`; опишите желаемый звук в тексте |
| `seed` | Целое `-1`…`2147483647`; одинаковый seed не гарантирует одинаковое видео |
| `watermark` | Boolean метки AI Generated, по умолчанию `false` |
| `return_last_frame` | Boolean, по умолчанию `false`; `true` запрашивает последний кадр результата в JPEG через `content.last_frame_url` у 2.0, 2.5, Mini и Fast |
| `output_format` | `mp4` по умолчанию; у 2.5 также `mov` |
| `omni_reference_task_type` | У 2.5: `auto`, `reference`, `edit`, `extend` |
| `draft` | У 2.5 `true` создаёт черновик 480p |
| `callback_url` | Публичный HTTPS-адрес для итогового уведомления; формат и обработка описаны в [результатах](/ru/docs/seedance/results) |
| `tools` | `[{"type":"web_search"}]` у 2.5, Mini и Fast; доступность зависит от подключения |
| `camera_fixed` | Boolean только у 2.5; также принимается `camerafixed`; не передавайте конфликтующие значения |
| `nsfw_check` | Необязательный boolean; возможность и поведение зависят от подключения |
| `negative_prompt`, `generation_type`, `service_tier` | Необязательные непустые строки; допустимые значения уточняйте для своего подключения; `service_tier` нельзя задавать для черновика или его финальной версии |

Для стандартного запроса используйте `seconds` и `size`. Модельные настройки задавайте явно через `resolution`, `aspect_ratio` и `generate_audio`. JSON booleans пишутся без кавычек. См. [референсы](/ru/docs/seedance/references) для ролей входных материалов.

`return_last_frame` возвращает кадр готового видео, а входная роль `last_frame` задаёт изображение для генерации. Это разные возможности. Получение кадра описано в [результатах](/ru/docs/seedance/results).

Для первого/последнего кадра, редактирования и продления используйте `aspect_ratio: "adaptive"`. Редактирование 2.5 требует `seconds: "-1"`. Роли первого/последнего кадра нельзя смешивать с `reference_image`. У 2.5 их можно сочетать с видео или аудио; у остальных моделей нельзя. Для 30 секунд нужна 2.5; Mini/Fast не принимают 1080p.
